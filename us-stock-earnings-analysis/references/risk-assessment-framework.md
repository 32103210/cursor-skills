# 风险评估框架

## 风险分类

### 1. 运营风险 (Operational Risk)

**客户集中度**:
- 前5大客户占收入比例
- 单一客户依赖度
- 客户合同期限和续约率

**供应链风险**:
- 关键供应商依赖
- 供应链地理集中度
- 替代供应商的可获得性

**人才风险**:
- 关键人物依赖（Key Person Risk）
- 人才流失率
- 招聘竞争力

**技术风险**:
- 技术债务水平
- 网络安全风险
- 技术替代风险

**执行风险**:
- 大型项目/转型的执行能力
- 并购整合风险
- 新市场扩张风险

### 2. 财务风险 (Financial Risk)

**流动性风险**:
- 现金储备是否充足
- 短期债务到期安排
- 信贷额度和可用性

**杠杆风险**:
- 债务总额和结构
- 利息覆盖倍数
- 债务契约条款和合规性

**汇率风险**:
- 海外收入占比
- 自然对冲程度
- 汇率敏感性

**信用风险** (金融业务):
- 贷款质量（不良率）
- 拨备覆盖率
- 贷款增速 vs 经济增速

### 3. 市场风险 (Market Risk)

**竞争风险**:
- 竞争格局变化速度
- 价格战风险
- 市场份额被侵蚀

**需求风险**:
- 宏观经济周期敏感度
- 消费者偏好变化
- 技术替代导致需求消失

**估值风险**:
- 当前估值 vs 历史和同行
- 估值隐含的增长预期是否过高
- 利率变化对估值的影响

### 4. 监管风险 (Regulatory Risk)

**合规风险**:
- 现有法规的合规成本
- 潜在的新法规影响
- 跨国运营的监管复杂性

**反垄断风险**:
- 市场地位是否引发反垄断关注
- 并购审查风险

**数据隐私**:
- 数据保护法规合规
- 数据泄露风险和潜在罚款

**行业特定监管**:
- 金融监管（资本要求、牌照）
- 环保法规（排放标准、碳税）
- 药品审批（FDA 审查）

### 5. ESG 风险

**环境 (E)**:
- 碳排放和气候风险
- 资源消耗和废物管理
- 环保法规合规

**社会 (S)**:
- 员工权益和劳工标准
- 供应链人权问题
- 社区关系和社会影响

**治理 (G)**:
- 董事会独立性和多样性
- 高管薪酬合理性
- 股东权益保护
- 关联交易和利益冲突

## 风险量化

### 风险评分矩阵

```
              影响程度
              低(1)    中(2)    高(3)
           ┌────────┬────────┬────────┐
  高(3)    │  中(3)  │ 高(6)  │极高(9) │
发         ├────────┼────────┼────────┤
生  中(2)  │  低(2)  │ 中(4)  │ 高(6)  │
概         ├────────┼────────┼────────┤
率  低(1)  │极低(1)  │ 低(2)  │ 中(3)  │
           └────────┴────────┴────────┘

风险评分 = 发生概率 × 影响程度

1-2: 低风险（监控）
3-4: 中风险（制定应急方案）
6:   高风险（积极管理）
9:   极高风险（可能影响投资论点）
```

### 风险量化方法

**情景分析**:
```
最佳情景 (概率 20%):
- 风险未发生
- 对估值的影响: +X%

基准情景 (概率 50%):
- 风险部分实现
- 对估值的影响: 0%

最差情景 (概率 30%):
- 风险完全实现
- 对估值的影响: -X%

风险加权影响 = Σ(概率 × 影响)
```

**敏感性分析**:
```
关键变量敏感性:

变量:        -20%   -10%   基准   +10%   +20%
─────────────────────────────────────────────
营收增速:    $XX    $XX    $XX    $XX    $XX
毛利率:      $XX    $XX    $XX    $XX    $XX
WACC:        $XX    $XX    $XX    $XX    $XX
终端增速:    $XX    $XX    $XX    $XX    $XX
```

## 使用建议

1. **全面性**: 不要只关注最明显的风险，系统性地覆盖所有类别
2. **动态更新**: 风险评估需要随新信息定期更新
3. **量化优先**: 尽量将风险量化，避免模糊的定性描述
4. **关注变化**: 风险等级的变化比绝对水平更重要
5. **平衡视角**: 同时识别上行风险（正面意外）和下行风险
