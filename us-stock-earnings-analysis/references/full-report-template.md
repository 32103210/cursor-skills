# 美股股权研究报告模板

本模板定义了完整的投资分析报告结构，整合定量和定性分析。每次生成分析报告时应遵循此结构。

## 报告结构

```
报告总长度参考:
- 快速报告: 覆盖第1-2节, ~500字
- 标准报告: 覆盖第1-6节, ~2000字
- 深度报告: 覆盖全部8节, ~4000字
```

---

### 第 1 节: 执行摘要 (Investment Summary)

这是整个报告最重要的部分，读者应该在30秒内获取核心结论。

```
═══════════════════════════════════════
[公司名称] ([Ticker]) — 投资分析摘要
═══════════════════════════════════════

推荐评级: [强烈买入 / 买入 / 持有 / 卖出 / 强烈卖出]
当前股价: $XX.XX（[日期] 收盘）
12个月目标价: $XX.XX（上行/下行空间: +/-XX%）

核心论点 (2-4句话):
[用最简练的语言说明为什么推荐买入/持有/卖出]

关键数据:
- 市值: $XXB
- P/E (TTM): XXx    |  P/E (Forward): XXx

Bull Case 目标价: $XX (+XX%)
Base Case 目标价: $XX (+XX%)
Bear Case 目标价: $XX (-XX%)
```

## 报告质量检查清单

每份报告完成后，逐项检查:

```
数据质量:
- [ ] 所有股价数据标注了时间点和来源
- [ ] 财报数据来自官方来源
- [ ] 关键数据经过交叉验证
- [ ] 没有使用 52 周极值作为当前价格

分析完整性:
- [ ] 包含定量分析（财务比率、趋势）
- [ ] 包含定性分析（竞争、策略、管理层）
- [ ] 包含催化剂分析（正面和负面）
- [ ] 包含风险评估
- [ ] 包含估值分析和目标价
- [ ] 如有近期股价异动，包含原因分析

投资结论:
- [ ] 给出明确的评级（买入/持有/卖出）
- [ ] 给出目标价和上行/下行空间
- [ ] 给出 Bull/Base/Bear Case
- [ ] 指明关键假设和监控指标
- [ ] 包含免责声明
```

## 免责声明模板

```
免责声明: 本报告基于公开信息分析，仅供参考，不构成投资建议。
投资有风险，决策需谨慎。数据截至 [日期]，可能存在滞后。
建议咨询专业财务顾问后做出投资决策。
```
