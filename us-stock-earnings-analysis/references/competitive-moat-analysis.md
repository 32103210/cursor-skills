# 竞争分析与护城河评估框架

## Porter 五力分析

Porter 五力模型从行业层面评估竞争强度和盈利吸引力。

### 1. 现有竞争者之间的竞争强度

**评估维度**:
- 竞争者数量和规模分布
- 行业增长速度（低增长 = 零和博弈）
- 产品差异化程度
- 退出壁垒高低
- 固定成本占比（高固定成本 → 价格战压力）

**评分标准**:
- **低威胁**: 少数玩家，差异化明显，行业快速增长
- **中威胁**: 适度竞争，一定差异化，稳定增长
- **高威胁**: 大量竞争者，同质化严重，增长停滞

### 2. 新进入者威胁

**评估维度**:
- 资本需求（进入成本）
- 规模经济效应
- 品牌认知和客户忠诚度
- 技术专利和知识产权壁垒
- 监管许可要求
- 渠道控制

**评分标准**:
- **低威胁**: 高资本壁垒，强品牌壁垒，严格监管
- **中威胁**: 中等壁垒，技术门槛可被跨越
- **高威胁**: 低壁垒，容易复制，资本需求低

### 3. 替代品威胁

**评估维度**:
- 替代品的可获得性
- 替代品的性价比
- 客户转换到替代品的成本
- 替代品的技术成熟度

**评分标准**:
- **低威胁**: 无可比拟的替代品，转换成本极高
- **中威胁**: 存在替代品但性价比或体验较差
- **高威胁**: 替代品性价比更高，转换成本低

### 4. 供应商议价能力

**评估维度**:
- 供应商集中度
- 原材料/服务的独特性
- 转换供应商的成本
- 供应商前向整合的可能性

**评分标准**:
- **低**: 大量供应商，标准化产品，易于切换
- **中**: 少数供应商，但产品可替代
- **高**: 极少数供应商，独特资源，切换困难

### 5. 客户议价能力

**评估维度**:
- 客户集中度
- 产品对客户的重要性
- 客户转换成本
- 客户后向整合的可能性
- 价格敏感度

**评分标准**:
- **低**: 分散的客户群，高转换成本，产品关键性高
- **中**: 部分大客户，中等转换成本
- **高**: 少数大客户主导，低转换成本，价格敏感

## 护城河 (Economic Moat) 分析

护城河是公司能够长期维持超额利润（ROIC > WACC）的可持续竞争优势。

### 护城河类型

#### 1. 网络效应 (Network Effects)

**定义**: 产品或服务的价值随着用户数量增加而增加。

**识别信号**:
- 用户增长呈现自我强化的正反馈循环
- 市场呈现赢者通吃格局
- 后来者很难打破现有网络的规模

**评估问题**:
- 网络效应是单边还是双边/多边？
- 网络效应是全局性还是局部性的？
- 用户能否同时使用竞品（multi-homing）？

**典型案例**: Meta (社交网络), Visa (支付网络), Shopee (电商平台买卖双边)

#### 2. 转换成本 (Switching Costs)

**定义**: 客户从当前产品/服务转到替代品所需付出的成本（金钱、时间、学习、数据迁移）。

**识别信号**:
- 极高的客户留存率（>90%）
- 产品深度嵌入客户业务流程
- 数据锁定效应

**评估问题**:
- 转换成本是金钱成本还是时间/学习成本？
- 竞争对手是否在积极降低转换障碍？
- 转换成本是否随使用时间增长？

**典型案例**: Salesforce (CRM数据锁定), Adobe (创意工具生态), Oracle (企业数据库)

#### 3. 成本优势 (Cost Advantages)

**定义**: 能以显著低于竞争对手的成本提供同等质量的产品或服务。

**来源**:
- 规模经济（固定成本被更大产量摊薄）
- 地理位置优势（靠近资源或市场）
- 独特资源获取（专利、矿产、人才）
- 流程创新（独特的生产或运营方式）

**评估问题**:
- 成本优势是否可持续？
- 竞争对手能否通过投资追赶？
- 成本优势的来源是什么？

**典型案例**: Walmart (规模采购), TSMC (制造工艺), Amazon (物流网络)

#### 4. 无形资产 (Intangible Assets)

**品牌**:
- 消费者愿意为品牌支付溢价
- 品牌认知度和信任度
- 品牌在目标市场的影响力

**知识产权**:
- 专利组合的广度和深度
- 专利到期时间表
- 专利被挑战的风险

**监管许可**:
- 行业准入许可（如银行牌照、电信牌照）
- 合规成本形成壁垒
- 监管变化的风险

**典型案例**: Apple (品牌), Pfizer (专利药), 中国移动 (电信牌照)

#### 5. 有效规模 (Efficient Scale)

**定义**: 市场规模有限，仅能容纳少数盈利企业，新进入者的加入会导致所有人无利可图。

**识别信号**:
- 自然垄断或寡头垄断格局
- 高固定成本 + 有限市场需求
- 基础设施型业务

**典型案例**: 公用事业, 铁路运输, 区域性废物处理

## 竞争格局分析

### 竞争定位矩阵

```
           高增长
             │
    挑战者    │    领导者
  (快速追赶)  │  (市场主导)
             │
  ───────────┼───────────
             │
    利基玩家  │    跟随者
  (细分市场)  │  (模仿策略)
             │
           低增长
  低份额 ←───┼───→ 高份额
```

### 竞争对手分析要点

对每个主要竞争对手，需要评估：

1. **市场份额**: 当前和趋势
2. **产品差异化**: 独特卖点
3. **定价策略**: 价格定位和趋势
4. **财务实力**: 盈利能力和资金储备
5. **战略方向**: 未来投资和扩张计划
6. **优劣势**: 相对于分析目标公司

## 使用建议

1. **动态视角**: 竞争优势不是静态的，需要持续跟踪
2. **定量验证**: 用 ROIC > WACC 的持续性来验证护城河假设
3. **反面思考**: 主动思考什么会破坏现有护城河
4. **行业特异性**: 不同行业的关键竞争因素差异很大
5. **客观评估**: 避免因持仓而高估护城河宽度
