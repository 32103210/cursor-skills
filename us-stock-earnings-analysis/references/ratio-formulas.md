# 财务比率计算公式速查表

## 盈利能力指标 (Profitability Ratios)

### ROE - 净资产收益率
```
ROE = 净利润 / 股东权益 × 100%
```
- **优秀**: > 15%
- **良好**: 10-15%
- **一般**: 5-10%
- **较差**: < 5%

### ROA - 总资产收益率
```
ROA = 净利润 / 总资产 × 100%
```
- **优秀**: > 10%
- **良好**: 5-10%
- **一般**: 2-5%
- **较差**: < 2%

### 毛利率 (Gross Margin)
```
毛利率 = (营收 - 营业成本) / 营收 × 100%
```
- **科技行业**: 通常 > 60%
- **零售行业**: 通常 20-40%
- **制造业**: 通常 30-50%

### 营业利润率 (Operating Margin)
```
营业利润率 = 营业利润 / 营收 × 100%
```
- **优秀**: > 20%
- **良好**: 10-20%
- **一般**: 5-10%
- **较差**: < 5%

### 净利率 (Net Margin)
```
净利率 = 净利润 / 营收 × 100%
```
- **优秀**: > 15%
- **良好**: 8-15%
- **一般**: 3-8%
- **较差**: < 3%

## 流动性指标 (Liquidity Ratios)

### 流动比率 (Current Ratio)
```
流动比率 = 流动资产 / 流动负债
```
- **优秀**: > 2.0
- **良好**: 1.5-2.0
- **一般**: 1.0-1.5
- **风险**: < 1.0

### 速动比率 (Quick Ratio)
```
速动比率 = (流动资产 - 存货) / 流动负债
```
- **优秀**: > 1.5
- **良好**: 1.0-1.5
- **一般**: 0.8-1.0
- **风险**: < 0.8

### 现金比率 (Cash Ratio)
```
现金比率 = (现金 + 现金等价物) / 流动负债
```
- **优秀**: > 0.5
- **良好**: 0.3-0.5
- **一般**: 0.1-0.3
- **较低**: < 0.1

## 杠杆指标 (Leverage Ratios)

### 资产负债率 (Debt to Assets)
```
资产负债率 = 总负债 / 总资产 × 100%
```
- **保守**: < 30%
- **适中**: 30-50%
- **激进**: 50-70%
- **高风险**: > 70%

### 债务权益比 (Debt to Equity)
```
债务权益比 = 总负债 / 股东权益
```
- **保守**: < 0.5
- **适中**: 0.5-1.0
- **激进**: 1.0-2.0
- **高风险**: > 2.0

### 利息保障倍数 (Interest Coverage)
```
利息保障倍数 = EBIT / 利息费用
```
- **优秀**: > 8
- **良好**: 5-8
- **一般**: 2.5-5
- **风险**: < 2.5

### 偿债覆盖率 (Debt Service Coverage)
```
偿债覆盖率 = (净利润 + 折旧 + 摊销) / (债务本金 + 利息)
```
- **优秀**: > 2.0
- **良好**: 1.5-2.0
- **一般**: 1.25-1.5
- **风险**: < 1.25

## 效率指标 (Efficiency Ratios)

### 资产周转率 (Asset Turnover)
```
资产周转率 = 营收 / 平均总资产
```
- **零售业**: 通常 > 2.0
- **制造业**: 通常 0.8-1.5
- **科技业**: 通常 0.5-1.0

### 存货周转率 (Inventory Turnover)
```
存货周转率 = 营业成本 / 平均存货
```
- **优秀**: > 12 (< 30 天)
- **良好**: 6-12 (30-60 天)
- **一般**: 4-6 (60-90 天)
- **较慢**: < 4 (> 90 天)

### 应收账款周转率 (Receivables Turnover)
```
应收账款周转率 = 营收 / 平均应收账款
```
- **优秀**: > 12 (< 30 天)
- **良好**: 8-12 (30-45 天)
- **一般**: 6-8 (45-60 天)
- **较慢**: < 6 (> 60 天)

### 应收账款周转天数 (Days Sales Outstanding)
```
DSO = (平均应收账款 / 营收) × 365
```
- **优秀**: < 30 天
- **良好**: 30-45 天
- **一般**: 45-60 天
- **较慢**: > 60 天

## 估值指标 (Valuation Ratios)

### P/E - 市盈率 (Price to Earnings)
```
P/E = 股价 / 每股收益 (EPS)
```
- **价值股**: < 15
- **市场平均**: 15-25
- **成长股**: 25-40
- **高估值**: > 40

### P/B - 市净率 (Price to Book)
```
P/B = 股价 / 每股净资产
```
- **低估**: < 1.0
- **合理**: 1.0-3.0
- **溢价**: 3.0-5.0
- **高估**: > 5.0

### P/S - 市销率 (Price to Sales)
```
P/S = 市值 / 营收
```
- **价值**: < 1.0
- **合理**: 1.0-3.0
- **成长**: 3.0-10.0
- **高估**: > 10.0

### EV/EBITDA - 企业价值倍数
```
EV/EBITDA = (市值 + 净债务) / EBITDA
```
- **低估**: < 8
- **合理**: 8-12
- **溢价**: 12-15
- **高估**: > 15

### PEG - 市盈增长比
```
PEG = P/E / 盈利增长率
```
- **低估**: < 1.0
- **合理**: 1.0-1.5
- **高估**: > 2.0

## 每股指标 (Per Share Metrics)

### EPS - 每股收益
```
EPS = (净利润 - 优先股股息) / 流通股数
```

### 每股净资产 (Book Value per Share)
```
BVPS = 股东权益 / 流通股数
```

### 每股股息 (Dividend per Share)
```
DPS = 总股息 / 流通股数
```

### 股息率 (Dividend Yield)
```
股息率 = (年度每股股息 / 股价) × 100%
```
- **高股息**: > 4%
- **中等**: 2-4%
- **低股息**: < 2%

### 股息支付率 (Payout Ratio)
```
支付率 = 每股股息 / 每股收益 × 100%
```
- **保守**: < 30%
- **适中**: 30-60%
- **激进**: > 60%

## 现金流指标 (Cash Flow Metrics)

### 自由现金流 (Free Cash Flow)
```
FCF = 经营现金流 - 资本支出
```

### 现金流利润率 (Operating Cash Flow Margin)
```
OCF Margin = 经营现金流 / 营收 × 100%
```
- **优秀**: > 15%
- **良好**: 10-15%
- **一般**: 5-10%
- **较差**: < 5%

### 现金转换周期 (Cash Conversion Cycle)
```
CCC = DSO + DIO - DPO
```
- DSO: 应收账款周转天数
- DIO: 存货周转天数
- DPO: 应付账款周转天数

## 风险评估指标

### Altman Z-Score (破产风险)
```
Z = 1.2×(营运资本/总资产) + 1.4×(留存收益/总资产) + 
    3.3×(EBIT/总资产) + 0.6×(市值/总负债) + 
    1.0×(营收/总资产)
```
- **安全**: > 2.99
- **灰色地带**: 1.81-2.99
- **破产风险**: < 1.81

### 贝塔系数 (Beta)
- **防御型**: β < 1
- **市场平均**: β = 1
- **进攻型**: β > 1

## 杜邦分析 (DuPont Analysis)

```
ROE = 净利率 × 资产周转率 × 权益乘数
    = (净利润/营收) × (营收/总资产) × (总资产/股东权益)
```

这个分解帮助识别 ROE 的驱动因素：
- **净利率**: 盈利能力
- **资产周转率**: 运营效率
- **权益乘数**: 财务杠杆

## 使用建议

1. **行业对比**: 不同行业的正常范围差异很大
2. **趋势分析**: 单一数据点意义有限，关注趋势
3. **综合评估**: 不要只看单一指标
4. **定性因素**: 结合管理层质量、竞争优势等
5. **宏观环境**: 考虑经济周期和行业周期
